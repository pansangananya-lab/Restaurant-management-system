# ระบบจัดการร้านอาหาร (Restaurant Management System)

โครงงานรายวิชา **30901-2008 การพัฒนาซอฟต์แวร์รูปแบบเดฟออฟส์ (DevOps)** กลุ่ม G3

## 📌 รายละเอียดโครงงาน (Project Overview)
ระบบเว็บแอปพลิเคชันสำหรับบริหารจัดการภายในร้านอาหารแบบครบวงจร ครอบคลุมการทำงานทั้งส่วนปฏิบัติการหน้าร้านและการบริหารจัดการหลังบ้าน พร้อมประยุกต์ใช้กระบวนการพัฒนาซอฟต์แวร์แบบ DevOps ร่วมกับ GitHub และ GitHub Desktop ในการทำงานร่วมกันเป็นทีม

## ✨ ขอบเขตการทำงานของระบบ (Features)
* **ส่วนปฏิบัติการหน้าร้าน (Front-of-House / Staff):**
  * ระบบจัดการโต๊ะอาหาร (แสดงสถานะโต๊ะว่าง, ไม่ว่าง, จอง)
  * ระบบบันทึกรายการอาหารและเครื่องดื่มตามโต๊ะ
  * ระบบแสดงสถานะออเดอร์ส่งไปยังห้องครัว (Kitchen Order Status)
  * ระบบคิดเงินและออกใบเสร็จรับเงิน
* **ส่วนบริหารจัดการหลังบ้าน (Back-of-House / Admin):**
  * ระบบจัดการข้อมูลเมนูอาหารและราคา (เพิ่ม, แก้ไข, ลบ)
  * ระบบจัดการสต็อกวัตถุดิบและแจ้งเตือนวัตถุดิบใกล้หมด
  * ระบบจัดการบัญชีผู้ใช้งาน (พนักงาน, แคชเชียร์, ผู้จัดการ)
  * หน้า Dashboard สรุปยอดขายรายวัน / รายเดือน และรายงานเมนูขายดี

## 🛠️ สถาปัตยกรรมระบบและเครื่องมือ (Tech Stack & Tools)
* **Frontend:** HTML/CSS/JS, React
* **Backend:** Node.js
* **Database:** MySQL
* **Infrastructure / Deployment:** Docker
* **Version Control / DevOps:** GitHub, GitHub Desktop

## 🌿 ข้อตกลงในการแตกสาขา (Branching Strategy)
* `main` : เก็บโค้ดเวอร์ชันที่สมบูรณ์และพร้อมใช้งานจริง (Production) เท่านั้น
* `develop` : รวบรวมโค้ดจากสมาชิกทุกคนเพื่อทดสอบระบบ (Integration)
* `feat/...` : สำหรับพัฒนาฟีเจอร์ย่อยตามหน้าที่ของสมาชิกแต่ละคน

## 👥 สมาชิกในกลุ่มและหน้าที่รับผิดชอบ (Team Members)
1. **Database:** ออกแบบฐานข้อมูลและเชื่อมต่อระบบ MySQL
2. **Frontend (คนที่ 1):** พัฒนาส่วนติดต่อผู้ใช้งานหน้าร้าน (Front-of-House)
3. **Frontend (คนที่ 2):** พัฒนาส่วนติดต่อผู้ใช้งานหลังบ้าน (Back-of-House)
4. **Backend:** พัฒนา API และระบบประมวลผลหลักด้วย Node.js
